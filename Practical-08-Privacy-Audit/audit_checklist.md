# Privacy Audit Checklist

Mark each item Yes / No / Not Applicable and attach evidence.

- [ ] Is there an inventory of personal data and processing purposes?
- [ ] Is each collection purpose documented and explained to people?
- [ ] Is only necessary data collected?
- [ ] Are access rights role-based and reviewed periodically?
- [ ] Is personal data protected in transit and at rest?
- [ ] Are retention periods defined and deletion actions evidenced?
- [ ] Are processors/vendors assessed and governed by written terms?
- [ ] Is there a process for handling data-principal requests?
- [ ] Is there a documented breach detection, escalation and response plan?
- [ ] Are employees trained on privacy and security?
- [ ] Are logs monitored and protected from unauthorized alteration?
- [ ] Are backups tested and access restricted?

For each No: record the risk, likelihood, impact, owner, target date and closure evidence.
